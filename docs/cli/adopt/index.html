Documentation / CLI

adopt

Validate, ingest, and persist one exact existing transcript source.

sh
transcript-lake [--data-dir <path>] adopt \
  --source {claude|codex|omp|droid|kimi} \
  --root <discovered-root> [--json]

Inputs#

--source and --root are required exactly once. The canonicalized root must equal a root returned for that runtime by sources. Symlink aliases, arbitrary archives, individual transcript files, hook telemetry, and unrecognized runtime names are refused.

Supported inputs are the adapters' established stores: Claude Code projects, Codex sessions, OMP sessions, Factory Droid session directories (including its complete *.settings.json objects), and Kimi work-directory sessions. This command does not define a generic interchange format.

Atomic validation#

Before mutation, every discovered candidate must resolve inside the selected root, be a regular adapter-owned file, and contain the runtime's supported JSON shape. Every complete nonempty JSONL line must be valid JSON with a recognized record type. An unsupported or malformed complete record rejects the whole adoption. An unterminated final line is not consumed and is counted as pending so a live writer can finish it later.

After preflight, the normal writer lease, masking, canonical partition, cursor, and Oko projection code ingests the source. The selection is written only after the destination accepts either new canonical events or verified unchanged files. Invalid input does not mark onboarding complete.

Duplicates and retained state#

The stable source id is derived from runtime plus canonical root. Existing Lake partitions and earlier source declarations are preserved. Byte cursors make a repeated unchanged source idempotent; new appends resume after the last durable offset. The selected id and all adopted declarations are retained in LAKE_DATA/sources.json. Once selected, stream follows only that exact source instead of every discovered root.

Result#

Human output names the source, status, runtime, root, imported/unchanged files, and imported events. --json additionally returns candidateFiles, candidateEvents, pendingIncompleteLines, conflicting, rejected, selected, and dataDir. Transcript text and credentials are never printed.

Failures#

Missing flags, duplicate flags, unknown runtime, absent or non-discovered root, empty source, unreadable file, path escape, malformed JSON, unsupported record type, writer-lease conflict, masking/write failure, or a selection-registry failure exits non-zero. The error names the path or contract that failed.

The same operation is available during first use as transcript-lake onboarding --source <runtime> --root <path>. --skip-source keeps an empty usable Lake and records no source fact.
